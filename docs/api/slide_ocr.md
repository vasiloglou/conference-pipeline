# slide_ocr.py - Vision LLM Slide OCR

LLM-driven slide OCR pipeline that outputs structured JSON per slide.

## Location

`src/conference_pipeline/slide_ocr.py`

## Helpers

```python
def load_slide_sync(slides_dir: Path, include_skipped: bool = False) -> list[SlideInfo]:
    """Load slide timestamps from slides/sync.json (or images fallback)."""


def load_transcript_segments(transcripts_dir: Path) -> list[dict]:
    """Load timestamped segments from transcripts/segments.json."""


def get_transcript_context(
    slide_timestamp: float,
    next_slide_timestamp: float | None,
    segments: list[dict],
    context_before: float = 30.0,
    context_after: float = 30.0,
) -> TranscriptContext | None:
    """Build transcript context around a slide timestamp."""
```

Notes:
- `transcripts/segments.json` is required for transcript context; if missing, OCR runs without context.
- `slides/sync.json` is generated by `StorageBackend.export_slide_sync_data` when slide timestamps exist.

## Services

### SlideOCRService (Protocol)

```python
class SlideOCRService(Protocol):
    async def ocr_slide(
        self,
        image_path: Path,
        title: str,
        transcript_context: str | None = None,
    ) -> str:
        """Return OCR output as raw text (JSON formatted by prompt)."""
```

### OpenAISlideOCRService / AnthropicSlideOCRService / GeminiSlideOCRService

```python
class OpenAISlideOCRService:
    def __init__(self, api_key: str, model: str = "gpt-5.6-luna", max_tokens: int = 4096):
        ...

class AnthropicSlideOCRService:
    def __init__(self, api_key: str, model: str = "claude-sonnet-5", max_tokens: int = 4096):
        ...

class GeminiSlideOCRService:
    def __init__(self, api_key: str, model: str = "gemini-3.1-flash-lite-preview", max_tokens: int = 4096):
        ...
```

`FallbackSlideOCRService` wraps a primary provider and a quality fallback. The
default production plan uses OpenAI `gpt-5.6-luna` as primary image parsing and
Gemini `gemini-3.1-flash-lite-preview` only for failed or low-confidence slide
parses.

## Pipeline

### SlideOCRPipeline

```python
class SlideOCRPipeline:
    def __init__(
        self,
        ocr_service: SlideOCRService,
        max_concurrent: int = 3,
        max_rpm: int = 30,
    ):
        ...

    async def process_presentation(
        self,
        pres_dir: Path,
        title: str,
        show_progress: bool = True,
        parallel: bool = True,
    ) -> list[OcrResult]:
        """Process all slides and write ocr/slide_###.json files."""
```

Outputs:
- `ocr/slide_###.json` per slide (structured JSON with slide text, visual elements, references, etc.)

## OCR Model Benchmark

Use the dry-run mode first, then add `--live` only after provider/budget
approval:

```bash
.venv/bin/python -m conference_pipeline.ocr_benchmark run \
  --workspace conferences/iclr2025 \
  --sample-size 12 \
  --budget-cap-usd 30 \
  --per-call-timeout-seconds 60 \
  --json
```

The benchmark compares lower-cost OpenAI, Anthropic, and Gemini image parsers
against an OpenAI authority (`gpt-5.6-sol`, falling back to `gpt-5.6-terra`) and writes a
receipt under `storage/transcription-ocr/ocr-model-benchmark/`.

## Usage Example

```python
from conference_pipeline.slide_ocr import SlideOCRPipeline, create_slide_ocr_service
from pathlib import Path

service = create_slide_ocr_service(settings)
pipeline = SlideOCRPipeline(service, max_concurrent=3, max_rpm=30)

results = await pipeline.process_presentation(
    Path("conferences/neurips2025/decks/paper-123"),
    title="Example Talk",
)
```
