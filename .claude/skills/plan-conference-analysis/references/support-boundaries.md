# Support Boundaries

Use exactly these support labels:

- `live`
- `dry-run`
- `mock`
- `unsupported`
- `planned`
- `dry-run/mock only`
- `needs live proof`

New conference planning defaults to `dry-run/mock only` unless live proof
receipts exist. Crawl, transcription, analysis, podcast, and presentation
production must not be described as live-supported without receipts. Use
`unsupported`, `planned`, or `needs live proof` when support is absent or
unproven.

Provider cost estimates are approval forecasts, not execution proof. A
full-pipeline estimate can unblock an approval decision, but live support still
requires conference-local execution receipts and artifact evidence.
